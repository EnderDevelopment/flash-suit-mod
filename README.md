# Flash Suit Mod

A detailed superhero suit mod for Minecraft.

## Features

- Highly detailed superhero suit inspired by the CW Flash costume
- Special effects including electric sparks and sound when sprinting

## Requirements

- Minecraft 1.20.4
- Fabric Loader 0.14.0 or higher

## Installation

1. Download the mod JAR file from the [releases page](https://github.com/EnderDevelopment/flash-suit-mod/releases).
2. Place the JAR file in your `mods` folder.
3. Launch Minecraft with the Fabric profile.

## Usage

1. Craft or obtain the Flash Suit in-game.
2. Equip the Flash Suit to wear it.
3. Sprint to see the special effects.

## Configuration

No additional configuration is required. The mod works out of the box.
